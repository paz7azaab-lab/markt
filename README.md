# مارکت | Markt

نمونه اولیه‌ی واکنش‌گرا برای یک بازار چندمنظوره: کالا، عمده‌فروشی، خدمات دیجیتال، خدمات محلی و تأمین کسب‌وکار.

## وضعیت فعلی
- رابط فارسی و راست‌چین، مناسب موبایل و دسکتاپ
- جست‌وجو و فیلتر دسته‌بندی
- ذخیره‌کردن آگهی‌ها در مرورگر
- فرم‌های آزمایشی ثبت آگهی و ثبت درخواست
- نمایش جزئیات آگهی
- بدون وابستگی به بک‌اند یا کلید API

**مهم:** این نسخه یک نمونه‌ی سمت کاربر است. آگهی‌های اولیه نمایشی‌اند؛ فرم‌ها فقط در همان مرورگر کار می‌کنند. حساب کاربری واقعی، پیام‌رسانی، انتشار عمومی آگهی‌ها، پرداخت، امتیازدهی و مدیریت معامله هنوز پیاده‌سازی نشده‌اند.

## اجرای محلی
فایل `index.html` را در مرورگر باز کنید. برای انتشار روی GitHub Pages به سرویس یا هزینه‌ی جداگانه‌ای نیاز نیست.

## فعال‌سازی GitHub Pages
در مخزن GitHub به مسیر **Settings → Pages** بروید. در بخش **Build and deployment**، گزینه‌ی **Deploy from a branch** را انتخاب کنید، شاخه‌ی **main** و پوشه‌ی **/(root)** را بگذارید و **Save** را بزنید. پس از پایان انتشار، نشانی نمایش‌داده‌شده در همان صفحه را باز کنید.

## فایل‌ها
- `index.html` ساختار صفحه و فرم‌ها
- `styles.css` طراحی واکنش‌گرا
- `app.js` جست‌وجو، فیلترها و تعاملات نمونه
