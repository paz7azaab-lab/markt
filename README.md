# گیم‌مارکت | Game Account Marketplace

نسخه اولیه‌ی موبایل‌محور برای بازار ایرانی آگهی‌های اکانت بازی‌های مختلف.

## امکانات فعلی
- رابط فارسی و راست‌چین با طراحی واکنش‌گرا
- آگهی‌های کاملاً نمایشی برای چند بازی و پلتفرم
- جست‌وجو و فیلتر موبایل، کامپیوتر و کنسول
- ذخیره آگهی‌ها در مرورگر
- فرم ساخت پیش‌نمایش آگهی در همان مرورگر
- هشدارهای امنیتی درباره قوانین بازی، اطلاعات ورود و نبود پرداخت امانی

## محدودیت‌های مهم
این نسخه فقط رابط کاربری سمت مرورگر است. آگهی‌ها به کاربران دیگر ارسال نمی‌شوند و روی دستگاه فعلی باقی می‌مانند. ورود و احراز هویت، پایگاه داده، پیام‌رسانی، مدیریت اختلاف، تأیید فروشنده و پرداخت واقعی پیاده‌سازی نشده‌اند. **هیچ پرداخت امانی یا تضمین معامله‌ای در سایت فعال نیست.**

برخی بازی‌ها فروش یا انتقال اکانت را ممنوع می‌کنند. پیش از فعال‌سازی هر بازی باید قوانین رسمی آن و الزامات قانونی/پرداختی سرویس در ایران بررسی شوند. از دریافت یا انتشار رمز، کد بازیابی یا اطلاعات حساس حساب‌ها خودداری شود.

## درآمد پیشنهادی
پس از اعتبارسنجی بازار و راه‌اندازی قانونی پرداخت امانی توسط تأمین‌کننده‌ی مجاز، می‌توان کارمزد شفاف از معاملات موفق دریافت کرد. تا آن زمان این سایت نباید پول خریدار را نگه دارد یا ادعای تضمین معامله داشته باشد.

## اجرای محلی و انتشار
فایل `index.html` را باز کنید یا در GitHub به مسیر **Settings → Pages** بروید و انتشار از شاخه‌ی `main` و پوشه‌ی `/(root)` را فعال کنید. انتشار استاتیک می‌تواند رایگان باشد؛ امکانات سمت سرور معمولاً به بک‌اند و پایگاه داده نیاز دارند.

## مسیر بعدی
1. بررسی قوانین هر بازی و انتخاب بازی‌های مجاز.
2. مصاحبه با خریداران و فروشندگان بالقوه و جذب اولین آگهی‌های واقعی.
3. افزودن بک‌اند امن، حساب‌ها، گزارش تخلف و پنل مدیریت.
4. بررسی امکان استفاده از تأمین‌کننده‌ی مجاز پرداخت امانی، قراردادها و سازوکار حل اختلاف.
5. اجرای آزمایشی محدود قبل از دریافت کارمزد واقعی.
